# TodoApp

Шағын офлайн Android қолданбасы: күнделікті тапсырмаларды қосу, орындау және басқару.

## Технологиялар

- Kotlin, Jetpack Compose және Material 3
- Navigation Compose
- Room Database
- ViewModel және Kotlin Coroutines

## Іске қосу

Android Studio арқылы жобаны ашып, Gradle синхрондауын орындаңыз. Android SDK 35 және JDK 17+ қажет.

```bash
./gradlew assembleDebug
```

Қолданба деректерді құрылғыдағы Room дерекқорында сақтайды және интернет рұқсатын сұрамайды.
